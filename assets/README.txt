ASSETS FOLDER — PRINTABLE CHARTS (POSTERS)
=============================================

Is folder mein 4 ready-made, rang-birange charts (poster) hain jo aap
seedhe browser mein khol kar print kar sakte hain aur bachcho ke
kamre/classroom ki deewar par laga sakte hain:

1. alphabet-chart.svg        -> English A-Z chart (Capital + Small + Shabd + Emoji)
2. varnamala-chart.svg        -> Hindi Varnamala chart (Swar + Vyanjan)
3. numbers-chart.svg          -> Ginti Chart 1 se 100
4. shapes-colors-chart.svg    -> Aakar (Shapes) aur Rang (Colors) chart

KAISE USE KAREIN:
------------------
- Kisi bhi .svg file ko double-click karke browser mein kholein.
- Browser ke Print (Ctrl+P / Cmd+P) option se A4/A3 size mein print
  karein — ye vector image hai isliye kitna bhi bada print karein,
  dhundhla (blurry) nahi hoga.
- Home page (index.html) ke "Printable Charts" section se bhi seedhe
  in charts ko khol sakte hain.

NAYA CHART BANANA HO TO:
--------------------------
Ye charts SVG (plain text + shapes) format mein hain, isliye kisi bhi
text editor mein khol kar rang, size ya text badal sakte hain. Agar
naya chart chahiye, kisi maujooda .svg file ko copy karke usmein
zaroori badlaav karke naye naam se save kar dein, aur index.html mein
uska ek naya "chart-card" link jod dein.
